# JCHK Sources

## Scope and citation convention

This guide is a teaching synthesis of the 18 supplied PDFs and eight supplied cabling PNGs. The PDF set contains **820 pages**. The user-guide volumes and appendices identify version **0.6.1, dated 1 August 2026**, and explicitly describe themselves as provisional. The lesson decks are the supplied v0.6.1 files; the cabling PNG filenames carry **22 July 2026**. These notes describe that source snapshot, not a claim that it is the latest fielded configuration.

**All page citations mean the 1-based PDF viewer page**, including covers and front matter. Printed page labels differ: for example, Appendix C-2 is PDF page 17. Lesson slide pages generally match PDF viewer pages. This convention makes each reference retrievable without guessing which numbering system is intended.

Each topic's Sources section points here and names the relevant pages. Explanatory examples and general definitions are synthesis; site addresses, device counts, baseline roles, and procedures are tied to named source pages. A conflict is recorded in [[JCHK Source Discrepancies]], not silently corrected into an invented baseline. The guide is organized for learning rather than reproducing the sources page by page.

**Original-file links** below point to the supplied files on this computer. They are external local-file links, not attachments copied into the vault. They depend on those files remaining at their current location. The notes themselves, their definitions, tables, and conceptual diagrams remain readable without opening the originals. Credentials shown in training sheets are not reproduced in this guide; use the authorized credential source for the actual kit.
